## 🔍 文件功能说明

### 核心业务逻辑
- **CustomGoods.php**: 处理商品定制属性设置、图案关联、定制信息获取等核心业务
- **CustomOrder.php**: 处理定制订单的创建、图片上传、订单关联等订单相关业务
- **CustomPattern.php**: 处理图案库的增删改查、分类管理、状态控制等图案管理业务

### 存储和数据库
- **CustomStorage.php**: 提供自定义文件上传、存储路径管理、文件验证等存储服务
- **CustomTableField.php**: 定义新增数据表结构和现有表字段扩展
- **install_custom_tables.sql**: 创建所有必要的数据库表和字段

### 用户界面
- **goods_custom.html/css/js**: 完整的用户端商品定制页面，支持图案选择、文字添加、图片上传等
- **goods_config.html**: 管理员配置商品定制属性的页面
- **pattern_*.html**: 图案库管理的完整界面
- **database_install.html**: 数据库安装的管理界面
